# Installation engine comparison (Story 2.1, Track 1)

Question: which installation engine, Archinstall JSON/CLI or native Arch commands, should
populate `install/engine/apply`, judged against one shared fixed reference-VM scenario?

This comparison is not a decision. The decision belongs to the user at the checkpoint and is
recorded in ADR 0002 only when the evidence is conclusive.

Prototypes:

- [`archinstall-json-cli/`](archinstall-json-cli/README.md)
- [`native-arch/`](native-arch/README.md)

Raw results: `evidence/prototypes/installation/<engine>/<run-id>/` (ignored).

## Scenario matrix

The scenario is derived from the Arch Installation Guide and the maintainer's real preferences.
It serves the prototypes only and does not define production installation policy.

Classification: `architecture` (fixed, not reopened), `preference` (personal preference),
`necessity` (technical necessity). Archinstall status is one of `JSON/CLI`, `native finalization`,
or `unsupported`.
